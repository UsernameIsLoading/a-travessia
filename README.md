# A TRAVESSIA — Flask

Aplicação Flask com login, tarefas, personagem, streaks e leaderboard compartilhado.

## Render
- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app`

O `index.html` fica na raiz do projeto de propósito, para facilitar o upload pelo GitHub e evitar erro `TemplateNotFound`.

## GitHub
Envie TODOS estes arquivos para a raiz do repositório:
- `app.py`
- `index.html`
- `requirements.txt`
- `render.yaml`
- `README.md`
